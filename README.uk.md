# AutoAccept CS2

[English](README.md) · **Українська**

Невеликий застосунок для Windows у треї. Він сам приймає знайдений матч **Counter-Strike 2**, повідомляє про це в Telegram
і вміє автоматично заходити в лобі, коли тебе запрошує друг зі списку.

## Правила використання

- Безкоштовно за ліцензією MIT. Програма надається «як є», без жодних гарантій: користуєшся нею на власний ризик.
- Це незалежний проєкт, **не пов'язаний із Valve чи Telegram і не схвалений ними**. Counter-Strike 2 і Steam є торговими
  марками Valve Corporation.
- Програма не чіпає пам'ять чи файли гри. Вона читає `console.log` CS2, імітує клік мишею по кнопці *Прийняти*
  (а в режимі друзів ще по віконцю *OK* гри) і спілкується з локальним інтерфейсом Steam. За дотримання правил сервісів,
  якими ти користуєшся, відповідаєш ти.
- Тримай токен свого Telegram-бота в таємниці: він зберігається у `data\config.json` поруч з exe.

## Швидкий старт (готовий реліз)

1. Відкрий сторінку [**Releases**](../../releases) (найновіший реліз зверху) і завантаж **`AutoAcceptCS2.exe`**
   (або **`.zip`**: розпакуй куди завгодно, там той самий exe і ці інструкції).
2. Поклади exe в окрему папку, наприклад `C:\Tools\AutoAcceptCS2\`. Не запускай його з-під архіву.
3. Двічі клікни по ньому. Якщо Windows SmartScreen попередить про невідомого видавця (exe не підписаний), натисни
   *Докладніше → Все одно виконати*. Іконка з'явиться в треї (внизу праворуч, можливо під стрілкою `^`).
4. У Steam додай CS2 параметр запуску `-condebug` (деталі в розділі [Перший запуск](#перший-запуск-5-хвилин)).
5. Іконка в треї → **Налаштування**: на сторінці *Клік* вкажи позицію кнопки «Прийняти» й увімкни *Автоприйняття*.

Налаштування й лог створюються в папці `data` поруч з exe. Щоб оновити програму, заміни exe на новий і залиш папку `data`.
Щоб видалити, вийди з програми через трей і видали її папку.

## Що він робить

- **Автоприйняття.** Стежить за `console.log` гри CS2. Коли матч знайдено, виводить CS2 на передній план і натискає *Прийняти*.
- **Telegram (за бажанням).** Повідомлення, коли матч знайдено, коли прийшов пінг сервера і коли резервація закінчилась.
  З власним ботом основними налаштуваннями можна керувати кнопками.
- **Запрошення друзів (за бажанням).** Коли друг зі списку запрошує тебе в CS2, програма заходить у його лобі.
  Якщо CS2 закрита, спершу запускає гру. Віконця підтвердження CS2 закриваються самі.
  Друга впізнає за Steam ID, а не за іменем. Поки запущена інша гра Steam, запрошення ігноруються.
- **Надійність.** Telegram отримує по одному повідомленню (без дублів і флуду), кожен мережевий запит має таймаут,
  програма переживає відсутній лог, заблокований конфіг і закриту гру.
- Інтерфейс англійською та українською, перемикається наживо. Темна тема Midnight Cyan.

## Вимоги

- Windows 10 або 11.
- Counter-Strike 2, встановлена через Steam.
- Лише для запуску з коду: Python 3.10 або новіший.

## Встановлення

### Варіант А: готовий exe (найпростіше)

1. Відкрий сторінку **Releases** цього репозиторію і завантаж `AutoAcceptCS2.exe`.
2. Поклади файл у будь-яку папку, наприклад `C:\Tools\AutoAcceptCS2\`. Програма портативна: налаштування й лог
   створяться в папці `data` поруч з exe.
3. Двічі клікни по файлу. Іконка з'явиться в треї (внизу праворуч, можливо під стрілкою `^`).

Windows SmartScreen може попередити про невідомого видавця, бо exe не підписаний: натисни *Докладніше → Все одно виконати*.

### Варіант Б: запуск або збірка з коду

```
git clone https://github.com/tankow79/AutoAcceptCS2.git
cd AutoAcceptCS2
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.venv\Scripts\python.exe autoaccept.pyw
```

Власний exe: запусти `build.bat` (результат: `out\AutoAcceptCS2.exe`).
Тести: `.venv\Scripts\python.exe -m pytest -q`. Лінтер: `.venv\Scripts\python.exe -m ruff check .`

## Перший запуск (5 хвилин)

1. **Дозволь CS2 писати консольний лог.** У Steam: Бібліотека → правий клік на *Counter-Strike 2* → Властивості →
   *Загальні* → *Параметри запуску*, впиши `-condebug`. Якщо гра запущена, перезапусти її.
   Без цього параметра CS2 не пише `console.log`, і програма нічого не побачить.
2. **Запусти AutoAccept CS2** і відкрий іконку в треї → **Налаштування**.
3. **Сторінка «Лог».** Лиши *Шукати автоматично* увімкненим: програма шукає в бібліотеках Steam. Якщо лог не знайдено
   (про це скаже сторінка «Статус»), вимкни автопошук і вкажи `...\game\csgo\console.log` вручну.
4. **Сторінка «Клік»: позиція кнопки «Прийняти».** Запусти CS2, дійди до екрана, де видно *Прийняти*
   (або скористайся тестовою гарячою клавішею), далі *Калібрування мишею*: наведи курсор на кнопку *Прийняти* і натисни
   гарячу клавішу захоплення (за замовчуванням **Ctrl+F8**). Позиція зберігається у відсотках вікна гри, тому працює
   і після зміни розрішення. **Ctrl+F9**: тестовий клік.
5. **Сторінка «Загальні».** Увімкни *Автоприйняття*. За бажанням увімкни *Запуск з Windows*.

Для базової роботи цього досить. Сторінка «Статус» показує, чи знайдено лог і чи видно гру.

## Налаштування по сторінках

| Сторінка | Для чого |
| --- | --- |
| **Статус** | Поточний стан: автоприйняття, чи знайдено лог, чи запущена CS2, кількість прийнятих матчів. |
| **Загальні** | Перемикач автоприйняття, запуск з Windows, виводити CS2 наперед, звук при матчі, ігнорування повторів (пауза). Мова інтерфейсу: перемикач унизу вікна. |
| **Клік** | Позиція кнопки «Прийняти» (% вікна), затримка перед кліком, кількість кліків та інтервал, гарячі клавіші. |
| **Telegram** | Токен бота, ID чату, кнопка тесту, які події надсилати, перемикач керування. |
| **Друзі** | Запрошення друзів: перемикач, список Steam ID, перезапуск Steam, калібрування OK. |
| **Лог** | Автоматичний або ручний шлях до `console.log` і ключове слово матчу (за замовчуванням `match_id`). |

Налаштування діють одразу і зберігаються в `data\config.json` поруч з exe. Лог програми: `data\app.log`.

## Сповіщення в Telegram

1. У Telegram відкрий [@BotFather](https://t.me/BotFather), надішли `/newbot`, виконай кроки й скопіюй **токен**
   (виглядає як `123456789:AA...`).
2. Відкрий свого нового бота й натисни **Start** (бот не може писати першим).
3. Дізнайся свій **ID чату**: число твого приватного чату. Поле описано в документації Telegram,
   [метод sendMessage](https://core.telegram.org/bots/api#sendmessage); ID покажуть боти на кшталт `@userinfobot`.
4. У програмі: Налаштування → **Telegram**: увімкни, встав токен і ID чату, натисни **Тест**.
5. Вибери, які події хочеш отримувати.

### Керування з Telegram (за бажанням, лише власний бот)

Увімкни *Керування з Telegram* на сторінці Telegram, потім надішли боту **/start**. З'являться кнопки для
автоприйняття, звуку, запрошень друзів, вибору сповіщень і мови.

> Telegram дозволяє лише **одній** програмі читати повідомлення бота. Користуйся цим зі **своїм ботом**. Спільний бот
> для кількох людей може надсилати сповіщення, але керування на ньому має бути вимкнене. Бот слухається лише твого
> приватного чату.

## Запрошення друзів (за бажанням)

Дає змогу другові затягнути тебе в лобі без жодних твоїх дій.

1. Налаштування → **Друзі**: увімкни *Приймати запрошення від друзів зі списку*.
2. Встав Steam ID друзів у список, по одному в рядок або через кому. Підходить: Steam ID64 (`7656119…`), ID акаунта,
   посилання на профіль `https://steamcommunity.com/profiles/…` або власне посилання `https://steamcommunity.com/id/name`.
   Імена, знайдені в локальних даних Steam, показуються під списком.
3. Натисни **Перезапустити Steam** (двічі: другий клік підтверджує). Steam відкриє локальний порт для налагодження,
   який слухає програма. Це потрібно **один раз**. Після перезавантаження ПК чи перезапуску Steam нічого робити не треба.
4. Натисни **Калібрувати OK**, дочекайся віконця CS2 (*Join another game?* або *Failed to join*) і один раз клікни на ньому
   **OK**. Програма запам'ятає, де OK **для цього розміру вікна**. Після зміни розрішення гри відкалібруй знову
   (програма нагадає про це в Telegram).
5. Попроси друга надіслати запрошення. Рядок статусу на сторінці «Друзі» показує, що бачить програма.

Що відбувається далі: запрошення читається зі Steam, друг має бути в списку, програма заходить у лобі.
Якщо CS2 закрита, вона запускає гру, чекає меню, заходить у лобі й натискає OK на віконці гри.
Якщо запущена інша гра Steam, запрошення ігнорується.

**Про порт налагодження.** Програма створює порожній файл `.cef-enable-remote-debugging` у папці Steam. Тоді Steam
слухає `127.0.0.1:8080`, лише на цьому ПК і ніколи з мережі. Будь-яка програма на твоєму ПК може керувати інтерфейсом
Steam через цей порт, тому вимкни функцію й видали файл, якщо тобі це не підходить. Якщо порт 8080 зайнятий іншою
програмою, рядок статусу назве її.

## Часті проблеми

| Проблема | Що робити |
| --- | --- |
| «Лог не знайдено» | Додай `-condebug` до параметрів запуску CS2, перезапусти гру або вкажи `console.log` вручну на сторінці «Лог». |
| Клік не влучає в «Прийняти» | Відкалібруй ще раз на сторінці «Клік» (Ctrl+F8 з курсором на кнопці). |
| «Тест» Telegram не проходить | Перевір токен, натисни Start у боті, перевір ID чату. Хибні налаштування ставлять відправку на паузу, виправлення її відновлює. |
| Друзі: «чекаю на Steam» | Натисни **Перезапустити Steam** один раз. |
| Друзі: «порт 8080 займає …» | Закрий цю програму й перезапусти Steam. |
| Клік по OK промахується | Натисни **Калібрувати OK** ще раз для поточного розрішення. |
| exe не перезбирається | Програма ще працює й блокує файл: спершу вийди з неї через трей. |

## Приватність і безпека

- Нічого нікуди не надсилається, окрім Telegram-повідомлень, які ти ввімкнув, і (для посилань на профіль
  `steamcommunity.com/id/name`) одного запиту на steamcommunity.com.
- Токен бота зберігається у `data\config.json` відкритим текстом: тримай цю папку приватною й нікому її не передавай.
- Програма не читає й не змінює пам'ять гри і не надсилає жодного вводу, окрім кліку мишею по *Прийняти*, а в режимі
  друзів ще кліку по віконцю *OK* гри.
