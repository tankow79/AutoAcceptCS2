# AutoAcceptCS2
Windows tray app (Python + PyQt6): watches the CS2 console.log for a match-found keyword, focuses CS2, clicks Accept in the game window, optionally sends Telegram.
Layout: `acs/` package + `autoaccept.pyw` entry. winapi.py (ctypes, data dir next to exe), settings.py (JSON `data/config.json`), watcher.py (tail console.log), accept.py (focus+click), notifier.py (Telegram queue), tgcontrol.py (settings as inline buttons in the user's OWN bot: one getUpdates reader per bot, owner private chat only, whitelisted keys), icon.py (Pillow-drawn icon), invite.py + cdp.py + friends.py (auto-accept friend invites: Steam CEF debug port 127.0.0.1:8080 hook -> steam://joinlobby link -> Enter on CS2's confirmation boxes; whitelist by Steam ID, vanity links resolved online), theme.py + ui.py + widgets.py + icons.py (Midnight Cyan, minimal cards; all texts via i18n.py EN/UK, live switch), app.py (tray + styled menu).
Env: `.venv` (Python 3.13). Run: `.venv\Scripts\python.exe autoaccept.pyw`. Lint: `.venv\Scripts\python.exe -m ruff check .`. Tests: `.venv\Scripts\python.exe -m pytest -q`. Build: `build.bat` -> out/AutoAcceptCS2.exe.
Rules: work on `main`, no push/tag/release by Claude. Tests never touch real config/network/clicks (use tmp_path, mock Accepter/Notifier). Qt tests use QT_QPA_PLATFORM=offscreen.
The user's real instance may hold the single-instance mutex and lock out/*.exe: ask them to quit it before building/smoke-running.
Agents (.claude/agents): acs-explorer (haiku, read-only), acs-tester (sonnet), acs-reviewer (sonnet), acs-docs (haiku), acs-release (sonnet). Same model split as the Scum_chat_translate project.
